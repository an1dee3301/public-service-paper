# Documentary coding files

These are preserved coding records, not newly adjudicated estimates. The first-pass automated coder, the second automated coder, and the author's single blind coding are different records; automated agreement does not establish human reliability.

- `terms/`: original codebook, first pass, bounded-excerpt second coding, full-document recoding and adjudication; supplier names are retained as the public-terms audit's subjects.
- `tenders/`: original and revised codebooks, earlier outputs, 109 revised-screen rows and comparison with the author's 20-document sheet. There are 82 relevant revised rows; earlier coding is kept for reconciliation. The tender source table contains 184 document rows but 182 distinct procurement identifiers. Platform brands outside the public-terms audit are replaced with `[platform]`.
- `contracts/`: coded outcomes and eligibility records. Supplier identity fields, contract-object prose and free-text model rationales have been removed from the large panel for privacy. IDs, classifications, financial quantities, dates and outcome flags are retained. The blank/completed human sheets retain bounded contract-object excerpts needed to interpret the author's 50 codes; platform brands are masked.
- `human/`: both original blind templates and completed Coding tabs as CSV, preserving row order, field names and values. Local text paths are reduced to basenames; workbook properties, instructions and time-spent fields are not distributed.
- `comparisons/` and `comparison_readout.md`: preserved counts, confusion matrices and disagreement readouts. Original internal file references in historical readouts may name files not distributed; released inputs are indexed in `../POINTERS.md`.

Full documents, network clients, raw request/response batches and private working records are excluded. Reproducing original automated responses requires the frozen outputs supplied here; no paid or authenticated service is needed to read them. These tables do not establish current contract terms or causal effects.
